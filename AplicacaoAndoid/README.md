# LoginFirebase

Aplicação Android desenvolvida em Kotlin utilizando Firebase Authentication e Cloud Firestore.

## Funcionalidades

- Login com e-mail e senha
- Validação de campos
- Autenticação com Firebase
- Consulta ao Firestore
- Sessão persistente
- Logout

## Tecnologias

- Kotlin
- XML
- Firebase Authentication
- Cloud Firestore
- Material Design 3

## Estrutura

```
LoginFirebase
│
├── app
├── build.gradle.kts
├── settings.gradle.kts
└── gradle.properties
```

## Firebase

Adicionar o arquivo `google-services.json` na pasta:

```
app/
```

Após isso sincronizar o Gradle.
