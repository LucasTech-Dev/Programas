ESTUDO DE CASO

Sistema de Biblioteca

Node.js Supabase Firestore

⚠️ O Problema

Dificuldade de controle no fluxo de empréstimos e falta de centralização da consulta ao catálogo físico e digital de livros na instituição.

💡 A Solução

Aplicação web integrada com rotas centralizadas, sincronização automática do status de devolução e consulta otimizada de acervo.

Desafios Técnicos Solucionados

Unificação de múltiplas origens de dados:

O maior desafio foi garantir o desacoplamento entre a camada de apresentação e os diferentes provedores de banco de dados. Foi implementada uma camada Service no Node.js para encapsular requisições e padronizar o payload de retorno.
